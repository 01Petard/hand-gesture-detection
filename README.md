# Hand Gesture Detection

基于 MediaPipe Hands 实现的实时手部追踪与可视化项目，通过摄像头捕捉手部关键点，并以动态粒子和发光线条呈现手部骨架。

### 在线体验

**[在线演示](https://hand.bugstack.top/)**

### 功能特性

- 基于 MediaPipe 实时检测与追踪手部关键点。
- 支持双手追踪及手部骨架可视化。
- 使用 Canvas 绘制动态发光骨架与指尖粒子。
- 支持粒子拖尾与实时视觉反馈。

### 使用说明

访问在线演示页面并允许摄像头权限，将手部置于摄像头前，即可查看实时追踪效果。
